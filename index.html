카카오톡 주문 파서

카카오톡 공동구매 대화에서 주문과 취소를 읽어 시트로 정리하고, 수령일별 시트로 나누는 과정을 브라우저에서 직접 돌려 볼 수 있는 시연 페이지입니다. 상품 설정과 대화를 고쳐 보세요.

다른 시연대화 저장 도구지점 자동 로그인 흐름
시연용 가상 데이터입니다. 실제 프로그램은 PC 카카오톡 창을 10초마다 자동 저장해 구글 스프레드시트에 올립니다. 이 페이지는 같은 규칙을 브라우저 안에서만 재현하며, 입력한 내용을 어디에도 전송하거나 저장하지 않습니다. 구글 시트 연동 자체는 포함하지 않았고, 이름과 상품은 모두 예시입니다.

상품 설정 (시트 3~6행에 해당)

상품명 별칭은 사과/홍로 처럼 / 로 구분합니다. 수령일은 260312, 3.19, 3/19, 2026.3.19 형식을 읽고, 같은 수령일의 상품끼리 한 시트로 묶입니다.

카카오톡 대화 (내보내기 형식)

대기 중

형식: [작성자] [시간] 내용. 이어지는 줄은 직전 작성자의 메시지로 처리합니다. 작성자 이름에 "운영진"이 있으면 파싱하지 않습니다. 시뮬레이션은 가상 메시지를 몇 초 간격으로 추가하며, 실제 프로그램은 10초 주기입니다.

주문 시트 결과

확인 필요취소된 원본 주문운영진·시스템(제외) 수령 체크선입금 체크지연 체크
동작 규칙 보기
  • 주문: 딸기2 사과1 처럼 상품명 뒤의 숫자를 수량으로 읽습니다. 딸기 3, 딸기:3 도 인식합니다. 상품명 뒤에 한글이 더 붙어도(완숙토마토) 같은 상품으로 봅니다.
  • 취소: 딸기 취소요 는 같은 작성자의 가장 최근 딸기 주문 수량만큼 음수로 넣고, 그 원본 행을 주황색으로 표시합니다. 딸기 1취소요 는 -1 입니다.
  • 확인 필요(회색): 상품명이 하나도 안 맞는 메시지, 상품 없이 "취소요"만 쓴 메시지, 이전 주문을 찾지 못한 취소는 관리자가 보도록 표시합니다.
  • 운영진이 쓴 메시지는 이어지는 줄까지 파싱하지 않습니다.
  • 수령일별 시트: 시트 4행의 수령일이 같은 상품끼리 묶어 날짜별 탭을 만듭니다. 해당 상품에 수량이 있는 행만 옮기고, 메시지는 작성자와 시간 뒤에 그 날짜 상품의 수량만 다시 적고 대화 날짜 태그를 붙입니다. 체크 상태와 행 표시는 원본과 같이 유지됩니다.
  • 체크박스: 수령은 연노랑, 선입금은 연빨강, 지연은 연파랑으로 행 전체가 바뀌며, 여러 개를 켜면 수령, 선입금, 지연 순으로 우선합니다.
  • 결제금액은 행별 수량 × 판매가의 합이고, 잔여수량은 총수량에서 순주문수량(주문 + 취소 음수)을 뺀 값입니다.
