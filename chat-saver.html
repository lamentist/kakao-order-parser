PC 메신저 대화 저장 도구 (시연)

여러 채팅방의 대화를 일정 주기로 텍스트 파일로 저장하는 Windows 프로그램의 동작을 브라우저에서 흉내 낸 시연입니다. 사례 1의 주문 파서가 읽는 입력 파일을 만드는 도구입니다.

시뮬레이션입니다. 실제 도구는 Windows 데스크톱 프로그램(Python, tkinter, Win32)으로, 채팅 창을 앞으로 가져오지 않고 창마다 저장 단축키(Ctrl+S)를 보내 텍스트로 저장하며 실패하면 최대 3회 재시도합니다. 이 페이지는 그 흐름을 가상의 채팅방과 대화로 재현하며, 아무것도 전송·저장하지 않습니다.

설정

실제 도구도 채팅 창을 전면으로 가져오지 않아, 사용자가 다른 작업을 하는 동안 백그라운드에서 저장합니다.
