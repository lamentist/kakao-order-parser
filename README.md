# 카카오톡 주문 파서 (웹 시연)

카카오톡 오픈채팅방에 올라오는 주문 메시지를 규칙에 따라 읽어 상품별 수량으로 집계하는 과정을 보여 주는 시연 페이지입니다.

- 입력한 대화는 브라우저 안에서만 처리되며 서버로 전송하지 않습니다.
- 화면에 나오는 대화와 상품은 모두 시연용 샘플입니다. 실제 고객 정보는 없습니다.
- 주문, 취소("취소요", "1취소요"), 확인 필요(회색) 규칙으로 분류합니다.

## 추가 시연

- `chat-saver.html` : PC 메신저 대화 저장 도구 시뮬레이션 (저장 주기, 백그라운드 저장, 실패 시 3회 재시도)
- `auto-login.html` : 에이전트 연동 지점 자동 로그인 시뮬레이션 (사용자 요청 → 에이전트가 지점 로그인 프로그램 실행 → 로그인 → 작업, 기존 방식과 비교, 종료 코드 0~4) + 범용 자동 로그인(1단계) 설명

두 페이지 모두 가상의 지점·대화만 사용하며 실제 사이트 접속이나 계정 정보가 없습니다. 모든 처리는 브라우저 안에서만 이루어집니다.
